Проекты

  • Legacy Django Mailer — это сервис для создания и отправки рассылок с использованием HTML-макетов, отложенных рассылок, переменных в макетах и отслеживания открытий писем, где активно применялись legacy-инструменты, такие как Python 2.7 и другие устаревшие технологии. Администраторы настраивают рассылки через модальное окно с AJAX-запросами, а автоматизация и работа с очередями реализованы с помощью Redis, Celery и других инструментов, что подчеркивает сочетание устаревших и современных решений.

    — РЕПОЗИТОРИЙ
    — ВЕРСИЯ

  • Telegram-бот предназначенный для упрощения поиска коммерческой недвижимости для аренды или покупки. Бот предоставляет пользователям возможность быстро находить подходящие объекты недвижимости по заданным критериям, а также получать подробную информацию о каждом объекте, контактную информацию владельцев или агентов, и подписываться на уведомления о новых предложениях.

    — РЕПОЗИТОРИЙ
    — ПРЕЗЕНТАЦИЯ

  • API YaMDb — это платформа, где пользователи могут оставлять отзывы, ставить оценки и комментировать произведения из категорий «Книги», «Фильмы», «Музыка» и других, формируя их рейтинг. Администраторы управляют добавлением произведений, жанров и категорий, в то время как аутентифицированные пользователи могут оставлять отзывы и комментарии, а гости могут только просматривать контент.

    — РЕПОЗИТОРИЙ

  • Froggygram — платформа для любителей лягушек, где пользователи могут делиться информацией о своих питомцах. Авторизация через REST API обеспечивает доступ к добавлению, редактированию и удалению карточек с лягушками, а также к просмотру чужих профилей. После входа пользователь получает токен, который позволяет управлять только своими данными.

    — РЕПОЗИТОРИЙ
    — ВЕРСИЯ

  • Fitgram — это платформа для любителей фитнеса, где пользователи могут делиться своими планами тренировок, добавлять понравившиеся планы в избранное и подписываться на других авторов. Авторизация через REST API обеспечивает доступ к управлению личными данными.

# Документация к генератору SVG-файлов

## Описание проекта

Проект представляет собой инструмент для автоматической генерации SVG-файлов на основе данных, полученных из внешнего API и параметров, указанных в CSV-файле. Генерируемые SVG-файлы могут быть настроены с использованием различных параметров, таких как цвет, логотип, высота и другие. SVG-файлы снабжаются ссылками, что делает их кликабельными при условии их встраивания через `<object>`

## Структура проекта

### Основные модули и функции

#### 1. **`fetch_and_parse_svg(title, color, logo, logo_color)`**
   - **Описание**: Выполняет запрос к API для получения SVG-данных и парсит их.
   - **Параметры**:
     - `title` (str): Заголовок для SVG.
     - `color` (str): Цвет фона или текста.
     - `logo` (str): Логотип, который будет добавлен в SVG.
     - `logo_color` (str): Цвет логотипа.
   - **Возвращаемое значение**: Словарь с распарсенными данными SVG или `None`, если произошла ошибка.

#### 2. **`scale_parameters(parsed_data, new_height=None)`**
   - **Описание**: Масштабирует параметры SVG (ширину, высоту, координаты текста) с учетом заданного масштаба.
   - **Параметры**:
     - `parsed_data` (dict): Распарсенные данные SVG.
     - `new_height` (int, optional): Новая высота SVG. Если не указана, используется исходная высота.
   - **Возвращаемое значение**: Словарь с пересчитанными параметрами SVG.

#### 3. **`prepare_template_data(title, docs_href, scaled_data)`**
   - **Описание**: Подготавливает данные для подстановки в шаблон SVG.
   - **Параметры**:
     - `title` (str): Заголовок SVG.
     - `docs_href` (str): Ссылка на документацию.
     - `scaled_data` (dict): Масштабированные данные SVG.
   - **Возвращаемое значение**: Словарь с данными для шаблона.

#### 4. **`save_svg_to_file(template_data, template_path, output_directory, title)`**
   - **Описание**: Сохраняет сгенерированный SVG-файл на основе шаблона и подготовленных данных.
   - **Параметры**:
     - `template_data` (dict): Данные для подстановки в шаблон.
     - `template_path` (str): Путь к файлу шаблона SVG.
     - `output_directory` (str): Директория для сохранения результата.
     - `title` (str): Заголовок SVG (используется для формирования имени файла).
   - **Действие**: Создает SVG-файл в указанной директории.

#### 5. **`generate_custom_svg(title, color, logo, logo_color, docs_href, new_height=None)`**
   - **Описание**: Основная функция для генерации SVG-файла. Объединяет все шаги: получение данных, масштабирование, подготовку данных и сохранение файла.
   - **Параметры**:
     - `title` (str): Заголовок SVG.
     - `color` (str): Цвет фона или текста.
     - `logo` (str): Логотип.
     - `logo_color` (str): Цвет логотипа.
     - `docs_href` (str): Ссылка на документацию.
     - `new_height` (int, optional): Новая высота SVG.
   - **Действие**: Генерирует и сохраняет SVG-файл.

#### 6. **`read_params_from_csv(file_path)`**
   - **Описание**: Читает параметры из CSV-файла и возвращает список кортежей.
   - **Параметры**:
     - `file_path` (str): Путь к CSV-файлу.
   - **Возвращаемое значение**: Список кортежей вида `(title, logo, docs_href)`.

## Константы и настройки

- `NEW_WIDTH_SCALE_FACTOR`: Коэффициент масштабирования ширины SVG.
- `TEXT_LENGTH_SCALE_FACTOR`: Коэффициент масштабирования длины текста.
- `X_SCALE_FACTOR`: Коэффициент масштабирования координаты X.
- `Y_SCALE_FACTOR`: Коэффициент масштабирования координаты Y.
- `DATA_DIRECTORY`: Директория для хранения данных.
- `DATA_FILE`: Имя CSV-файла с параметрами.
- `TIME_SLEEP`: Пауза между генерацией SVG-файлов (в секундах).

## Пример использования

### 1. Установка зависимостей
Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv venv
```
Активируйте виртуальное окружение:
На Linux/MacOS:
```bash
source venv/bin/activate
```
На Windows:
```bash
source venv/Scripts/activate
```
Установите зависимости из файла requirements.txt:
```bash
pip install -r requirements.txt
```
Примечание: Тестирование проводилось на Python 3.11. 


### 2. Подготовка CSV-файла
Создайте CSV-файл с параметрами в следующем формате:

```csv
title,logo,docs_href
"Проект 1", "logo1", "https://example.com/docs1"
"Проект 2", "logo2", "https://example.com/docs2"
```

### 3. Запуск скрипта
```bash
python shield_generator.py
```
Скрипт прочитает параметры из CSV-файла, сгенерирует SVG-файлы и сохранит их в указанной директории.

### 4. Примечания
#### 1. Зависимости:
Для работы скрипта необходимы библиотеки ```requests```, ```csv```, ```string```, ```time```.
Убедитесь, что файл шаблона ```template.svg``` существует в текущей директории.
#### 2. Обработка ошибок:
Если файл CSV не найден или произошла ошибка при чтении, скрипт выведет соответствующее сообщение.
Если не удается получить или распарсить SVG-данные, генерация пропускается.
#### 3. Масштабирование:
Параметры масштабирования (```NEW_WIDTH_SCALE_FACTOR```, ```TEXT_LENGTH_SCALE_FACTOR``` и т.д.) можно настроить в зависимости от требований к выводу.

# Документация для генератора HTML на Python и Jinja2

## 1. Описание проекта

Проект представляет собой инструмент для автоматической генерации статического HTML-сайта на основе данных, хранящихся в CSV-файле, и HTML-шаблонов. Основная цель — упростить поддержку и масштабирование одностраничного сайта, разделяя содержимое (тексты, ссылки, изображения) и структуру (HTML).
